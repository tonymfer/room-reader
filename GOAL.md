# room-reader hackathon goal

/goal Build a deployed-ready Next.js app called room-reader verified by npm run test, npm run typecheck, npm run lint, npm run build, and manual demo-path checks while preserving: no secrets committed, no auth/database requirement, deterministic mock mode, Web Speech API guarded client-side only, localStorage fallback, and safety framing that personas are editable rehearsal assumptions, not psychological profiles.

Scope: one polished cohesive page, six required topics, CSS-only pixel audience, textarea fallback, deterministic report engine, Supabase optional only.

Decision rule between tries:
1. Make the full demo path work.
2. Make tests/build pass.
3. Make fallback modes reliable.
4. Improve visual polish.
5. Add Supabase persistence only if it does not endanger the demo.
6. Add optional LLM route only if mock mode remains stable.
7. Stop adding features once the demo works.

If blocked: report exact command, error, and safest fallback.
